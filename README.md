# Simulador de iPhone

Este projeto simula as funcionalidades do iPhone como Reprodutor Musical, Aparelho Telefônico e Navegador na Internet usando Java e conceitos de POO e interfaces.

## Funcionalidades
- Tocar, pausar e selecionar música
- Ligar, atender e iniciar correio de voz
- Navegar na internet com múltiplas abas

## Tecnologias
- Java
- POO (Programação Orientada a Objetos)
